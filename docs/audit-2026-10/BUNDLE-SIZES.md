# A2 — bundle sizes before / after

Measured with `npx vite build` (Vite 8.3.3 / rolldown), production mode, which loads `.env.production` (Firebase configured).
Before = `scratchpad/build-baseline2.log` (the merged tree at 2d165f0, before any phase-1 edits landed).
After = `scratchpad/build-a2.log` (the tree at the end of A2's work, so it also contains the other tracks' edits
up to that moment: C2's recharts removal, the Settings split, new pages). Generated by `scratchpad/a2-sizes.py`;
the chunk hash is stripped from names except for the `index.esm-*` Firebase package chunks, which only have a hash.
Sizes in kB as Vite prints them (gzip is Vite's estimate).

## Headline (A2's own changes)

| What | Before | After |
|---|---:|---:|
| JS before first React paint | **351.1 kB gzip in two serial stages** (136.2 entry set, then 214.9 of Firebase discovered by `initRepo()` after React had started) | **306.5 kB gzip in one parallel stage**: entry + 10 `modulepreload`s, all in `dist/index.html` |
| First contentful paint | after stage 2 (React `<Splash/>`) | after the HTML + CSS (`#root:empty` splash in index.html, same gradient and mark) |
| Firestore chunk (`re2js` stub) | 555.90 / 162.25 gzip | 412.01 / **118.90 gzip (−43.35)** |
| Demo repo + seed in the Firebase build | ~6 kB gzip eager (`data.js`, `repo.js`) | gone (verified: no seed string in `dist/assets`); and the demo build (`--mode e2e`) has no Firebase in its eager set |
| Fonts | Google Fonts CSS (render-blocking, cross-origin, not in the SW) + 5 weight files | 2 same-origin woff2 (latin 47 kB, latin-ext 83 kB; only the ranges the page draws are fetched), precached, `font-display: swap`, preloaded from index.html |
| `firebase/app-check` | eager inside `firebaseRepo` (13.6 kB raw) | lazy `index.esm-xovMmlD1.js` 14.06 / 5.16 gzip, only fetched when a site key is set |
| OCR cores (`dist/tesseract`, not precached) | 3 × 3.9 MB base64 `*.wasm.js` = 12 MB | 3 × (89 kB glue + 2.86 MB `.wasm`) = 8.6 MB; one pair is fetched per device, and the browser compiles the .wasm while it streams |
| Precache | 77 entries, 2104 KiB | 104 entries, 1798 KiB (more entries come from the other tracks' new chunks; the total fell with Firestore −144 kB raw and Insights −398 kB raw) |

Not A2's: `Insights.js` 118.89 → 7.42 gzip (C2 replaced recharts), `Profile.js` 19.11 → 4.19 and the new `Settings`/`Automation`/`Ai`/`Admin`/`Preferences`/`Data`/`Notifications` chunks (C3's Settings IA), `ExpenseForm.js` +5.9 (C1), `Misc.js` +14.3 (shared components other tracks moved there). `data.js` "+36" is a rename, not growth: it is now the chunk that holds `firebaseRepo` + `@firebase/auth` (the old `firebaseRepo.js` 42.03 gzip is "gone"); `index.esm-ZULyT70a.js` + `index.esm-Dz4kcgGz.js` are the pieces rolldown split off it.
